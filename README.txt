Circuit Market — Sample ERP

Open index.html in a modern browser. No installation or internet connection is required; the optional web fonts fall back to system fonts offline.

Presentation walkthrough
1. Explore Overview: live totals, channel split, recent orders and stock alerts.
2. Open Inventory and click a product for its resource details. Adjust stock with a reason.
3. Create an online or in-store order. Its quantity is deducted from shared inventory.
4. Open the order to update Processing → Shipped → Completed.
5. Visit Purchasing and receive a purchase order. Stock increases exactly once.
6. Add an employee in Employees; use search and location filtering.
7. Export CSV reports, review finances and inspect Customers.
8. Settings shows the activity log and lets you reset all demo data.

Scope
This is a local UI prototype with browser localStorage persistence. It has no backend, authentication, payments, real accounting, payroll, taxes, multi-user access, or external integration. Sales totals include all recorded orders. The trend chart is explicitly illustrative; other totals derive from workspace records. Seed orders and opening stock represent an existing business snapshot. Browser/file storage behavior varies; keep using the same browser and path. Reset in Settings to restore sample records. Use fictitious data only.

Files
index.html — application shell
styles.css — responsive interface
app.js — seed records and working interactions

Currency: USD. Reference date in the presentation header: November 10, 2026. New records use the current device date.
